Grocery Store Demo

This app demonstrates a FastAPI application backed by a PostgreSQL database. It connects as the application role (created in 0004_users/run.sql) which:

  • owns the application schema - full DDL (CREATE, ALTER, DROP) and DML on all its tables
  • cannot access the reporting schema

Template routes

Stores - view and add stores Staff - view and add staff members Orders - view and add orders

Reporting scripts

Reporting views are queried via standalone Python scripts that connect as the reporting user:

  • uv run python scripts/staff_count_by_store.py
  • uv run python scripts/orders_by_day.py
  • uv run python scripts/orders_by_store.py
  • uv run python scripts/orders_by_staff.py
