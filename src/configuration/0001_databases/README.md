# Databases

Usually the highest level of abstraction for application developers.

A database is the "home" for the data organised to be used, often at an application level.

The term "database" is often used to describe the server itself, or the general concept of storage but in this context it's the container - also known as a "logical database".

It's usually set at the app level (e.g. an entire web app uses a single logical database).

Postgres ships with a `postgres` database as a default connection target.
